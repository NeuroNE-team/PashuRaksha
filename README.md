# PashuRakshak AI

Livestock owners, vets and officials lack a unified, real-time system to detect animal-health risks at village, block and district levels. Late reporting, distant diagnostics and fragmented records delay containment, raise mortality and zoonotic risk, and cut incomes.

**PashuRakshak** is an offline-first livestock disease early-warning tool. It runs entirely on a local machine with no internet connection, scores the risk from reported symptoms, suggests a likely disease, and stores every assessment in a local SQLite database.

## How to launch?

1. If Python is installed on computer, download and launch the PashuRakshak.py file.

2. If Python is not installed on computer, download and launch pashurakshak_ai_web_app.html or pashurakshak_ai_mobile_app.html file.


Both of these files are designed to run offline and in any web browser.

This is a prototype, and was developed for better understanding of the problem statement. Any kind of data used is hypothetical and not true.

## Disclaimer

This tool provides a rule-based early-warning indication only. It is **not** a diagnosis. Always confirm suspected outbreaks with a qualified veterinarian and report notifiable diseases to the local animal husbandry department.
